SHEARING FRANCE V6.3 — ANDROID + GITHUB ACTIONS

Cette archive contient les fichiers web V6.3, le projet Capacitor et le workflow GitHub Actions pour générer un APK de test.

Sur GitHub :
1. Ouvrir le dépôt shearing-france-android.
2. Mettre à jour son contenu avec tous les fichiers de cette archive (y compris .github).
3. Commit sur main.
4. Aller dans Actions et attendre le workflow Build Shearing France Android APK.
5. Télécharger l'artefact Shearing-France-APK quand le workflow est vert.

La version V6.3 ajoute l'import photo OCR. La reconnaissance Tesseract est chargée depuis jsDelivr : la première lecture nécessite Internet. Les imports sont enregistrés localement en provisoire. La publication publique multi-utilisateur nécessite toujours un backend sécurisé, non inclus dans cette archive.
